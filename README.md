# java-racingcar-precourse

## 자동차 경주
사용자로부터 자동차 n대와 횟수를 입력받아 랜덤으로 경주를 실행해
횟수마다의 경주 과정을 보여줌. 그 후 최종 결과를 보여주고, 우승한 자동차의 이름을 출력하는
간단한 경주 게임

## 구현할 기능 목록
### 1. 자동차
   - 각 자동차 이름 입력 받기
   - 자동차 이름 쉼표로 구분
   - 이름은 5자 이하만 가능
### 2. 이동할 횟수 입력 받기
   - 시도 횟수 입력 받기
### 3. 게임 실행하기
   - 사용자로부터 입력 받은 횟수만큼 게임 실행
   - 전진하는 조건 : 0-9 사이의 무작위의 값을 구하고 그 값이 4 이상이 경우
   - 주어진 횟수 동안에 주어진 자동차 모두의 값을 구해 전진 또는 정지
### 4. 회차 별 실행 결과 출력
   - 자동차의 이동 거리와 함께 회차 별 실행 결과 보여주기
### 5. 우승자 출력
   - 모든 회차를 다 돌고 최종 우승자 출력
   - 우승자는 한 명 이상일 수 있으며, 우승자가 여러 명이 경우 쉼표(,)를 이용해 구분

### 예외 처리
- 자동차 이름이 조건에 맞지 않는 경우(자동차 이름이 5자를 초과할 경우)
- 자동차 이름 지정을 하지 않은 경우(공백, null일 경우)
- 시도 횟수의 입력값이 잘못된 경우(음수, 0, 문자 등)
